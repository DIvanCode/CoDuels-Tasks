# Два знака

## Условие

Вам дано трёхзначное число, и в вашем распоряжении три арифметические операции: сложение, вычитание и умножение. Вы должны между каждыми двумя цифрами поставить знак одной из операций таким образом, чтобы после вычисления результата выражения получилось максимальное число. Все операции должны быть различными, то есть вы не можете дважды использовать одну и ту же операцию.

Цифры менять местами нельзя. При вычислении результата выражения приоритеты операций сохраняются.

## Формат входных данных

Вам дано одно целое положительное число $n$ ($100 ≤ n ≤ 999$).

## Формат выходных данных

Выведите максимальное число, которое может получиться в результате вычисления получившегося выражения.
