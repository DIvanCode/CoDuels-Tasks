# Счастливый порядок

## Условие

Рустам занимается изучением натуральных чисел. В какой-то момент его заинтересовали \textitсчастливые числа. \textitСчастливыми Рустам называет натуральные числа, десятичная запись которых состоит только из цифр $4$ и $7$.

Мальчик начал исследовать различные способы упорядочить эти числа. Он решил, что хочет упорядочить все счастливые числа \textitлексикографически.

Так как счастливых чисел бесконечно много, Рустам просит вас помочь ему с исследованием и найти для него $n$-е счастливое число в лексикографическом порядке.

Напомним, что строка $a$ \textitлексикографически меньше строки $b$, если выполнено одно из двух условий:

\beginenumerate
\item Строка $a$ является префиксом строки $b$ (и при этом $a \neq b$).
\item Существует такое $i$ ($1 ≤ i ≤ \min(\lvert a \rvert, \lvert b \rvert)$), что $a_i < b_i$, и для любого $j$ ($1 ≤ j < i$) $a_j = b_j$.
\endenumerate

Число $x$ лексикографически меньше числа $y$, если десятичная запись числа $x$ лексикографически меньше десятичной записи числа $y$. Для определенности будем считать, что десятичная запись любого числа не содержит ведущих нулей.

## Формат входных данных

В единственной строке содержится целое число $n$ ($1 ≤ n ≤ 10^6$).

## Формат выходных данных

Выведите $n$-е счастливое число в лексикографическом порядке.
