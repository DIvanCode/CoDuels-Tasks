# Экскурсия

## Условие

На Всероссийскую командную олимпиаду школьников по программированию приехало $n$ делегаций из разных городов, $i$-я делегация состоит из $a_i$ человек. Организаторы олимпиады приготовили экскурсию для участников и сопровождающих, но поучаствовать в ней смогут не более $k$ человек. Все гости олимпиады хотят её посетить, но коллективы не планируют разделяться~--- каждая делегация должна либо поехать на экскурсию в полном составе, либо пропустить её.

Помогите организаторам выбрать максимальное количество делегаций, которые смогут поучаствовать в экскурсии.

## Формат входных данных

Первая строка содержит два целых числа $n$ и $k$ ($2 ≤ n ≤ 1000$, $3 ≤ k ≤ 10^8$)~--- количество делегаций и мест на экскурсии.

Вторая строка содержит $n$ целых чисел $a_i$ $(3 ≤ a_i ≤ 10^5)$~--- количество человек в $i$-й делегации.

## Формат выходных данных

Выведите одно число~--- максимальное количество делегаций, которые смогут поучаствовать в экскурсии.
