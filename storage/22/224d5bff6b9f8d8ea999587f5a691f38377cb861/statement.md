# Чёрная металлургия

## Условие

В Челябинске есть $n$ заводов. Изначально $i$-й производит $a_i$ деталей в секунду и работает ровно $b_i$ секунд в год. Таким образом, с $i$-го завода выходит $a_i · b_i$ деталей в год.

Правительство только отлаживает систему и каждый год вносит $q$ изменений одного из двух типов:
\beginenumerate
\item Все заводы с номерами от $L$ до $R$ должны увеличить производство на $x$ деталей в секунду. То есть, если $L ≤ i ≤ R$, то после этого изменения $i$-й завод начнет выпускать $a_i + x$ деталей в секунду.
\item Все заводы с номерами от $L$ до $R$ должны работать на $t$ секунд в год больше. То есть, если $L ≤ i ≤ R$, то после этого изменения $i$-й завод начнет работать $b_i + t$ секунд в год.
\endenumerate

После $i$-го изменения правительство хочет знать, сколько деталей будет произведено за год заводами с номерами от $A$ до $B$. Так как это число может быть очень большим, выводите его остаток от деления на $998\,244\,353$.

Обратите внимание, что $A$ и $B$ могут различаться для разных запросов. Для лучшего понимания прочитайте формат входных данных.

## Формат входных данных

В первой строке находится одно целое число $n$ ($1 ≤ n ≤ 10^5$)~--- количество заводов.

В $i$-й из следующих $n$ строк содержатся по два целых числа $a_i$ и $b_i$ ($1 ≤ a_i ≤ 10^9$, $1 ≤ b_i ≤ 3 · 10^7$)~--- количество деталей, которые $i$-й завод выпускает за секунду, и количество секунд, сколько $i$-й завод работает в течение года.

В следующей строке находится одно целое число $q$ ($1 ≤ q ≤ 10^5$)~--- количество изменений.

В каждой из следующих $q$ строк сначала содержится целое число $type$ ($1 ≤ type ≤ 2$), обозначающее тип текущего изменения.

Если $type = 1$, то следом на этой строке идут ещё $5$ целых чисел $L$, $R$, $x$, $A$, $B$ ($1 ≤ L ≤ R ≤ n$, $0 ≤ x ≤ 10^9$, $1 ≤ A ≤ B ≤ n$), описывающих операцию $1$ типа.

Если $type = 2$, то следом на этой строке идут ещё $5$ целых чисел $L$, $R$, $t$, $A$, $B$ ($1 ≤ L ≤ R ≤ n$, $0 ≤ t ≤ 3 · 10^7$, $1 ≤ A ≤ B ≤ n$), описывающих операцию $2$ типа.

Гарантируется, что после всех изменений $b_i$ не будут превосходить $3 · 10^7$.

## Формат выходных данных

Для каждого запроса выведите суммарное количество деталей, которые за год произведут заводы с номерами от $A_i$ до $B_i$, по модулю $998\,244\,353$ в отдельной строке.
