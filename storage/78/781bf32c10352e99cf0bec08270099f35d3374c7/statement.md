# Меховые подпоследовательности

## Условие

Недавно Миша устал от бесконечной прокрастинации и захотел решить какую-нибудь задачу. К сожалению, он неправильно прочитал первую же найденную им задачу, а ошибку заметил уже после того, как отправил решение на проверку. К счастью, изначальная задача оказалась несложной, и Миша все же решил ее. А теперь вам предстоит решить его задачу!

Вам дан массив из $n$ неотрицательных целых чисел. Ваша задача~--- посчитать количество последовательностей $i_1, i_2, ..., i_k$, таких что $1 ≤ i_1 < ... < i_k ≤ n$, а также для каждого $1 ≤ j ≤ k$ выполнено неравенство $\lvert a_i_j - M \rvert ≤ 1$, где $M = \mathrmmex ≤fta_i_1, ..., a_i_k \right$.

Напомним, что $\mathrmmex ≤fta_1, ..., a_n \right$~--- это минимальное целое неотрицательное число, которое отсутствует в множестве чисел $≤fta_1, ..., a_n\right$. Например, $\mathrmmex ≤ft0, 1, 2\right = 3$, а $\mathrmmex ≤ft2, 3\right = 0$.

## Формат входных данных

Первая строка содержит единственное целое число $n$ ($1 ≤ n ≤ 10^5$)~--- количество элементов в массиве.

Вторая строка содержит $n$ целых неотрицательных чисел $a_1, ..., a_n$ ($0 ≤ a_i ≤ 10^9$)~--- элементы массива $a$.

## Формат выходных данных

Выведите одно целое число~--- количество искомых последовательностей $i_1, i_2, ..., i_k$.

Так как ответ может быть достаточно большим, выведите остаток от деления ответа на число $998\,244\,353$.
