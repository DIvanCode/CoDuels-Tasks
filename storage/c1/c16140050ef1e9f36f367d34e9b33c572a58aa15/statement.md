# Весёлые замены

## Условие

\textitВёселой заменой в строке из маленьких латинских букв называется замена одной гласной буквы на любую другую гласную, гласными буквами в латинском алфавите считаются \ta, \te, \ti, \to, \tu, \ty. Остальные буквы в строке при этом не меняются. Например, \tlepka $\rightarrow$ \tlipka и \tlepka $\rightarrow$ \tlapka~--- весёлые замены, а \tlepka $\rightarrow$ \tkepka и \tlepka $\rightarrow$ \tlapki~--- нет.

Вам дана исходная строка и список строк. Для каждой строки из списка проверьте, можно ли получить её из исходной после нескольких (возможно, нуля) весёлых замен.

## Формат входных данных

Первая строка содержит исходную строку $s$ ($1 ≤ |s| ≤ 2000$).

Вторая строка содержит число $n$ $(1 ≤ n ≤ 2000)$~--- количество строк в наборе.

Следующие $n$ строк содержат по одной строке $t_i$ из набора ($1 ≤ |t_i| ≤ 2000$).

Все строки во входных данных состоят только из маленьких латинских букв.

## Формат выходных данных

Для каждой строки из списка выведите \tYES, если её можно получить из исходной после нескольких (возможно, нуля) весёлых замен, и \tNO в противном случае.
