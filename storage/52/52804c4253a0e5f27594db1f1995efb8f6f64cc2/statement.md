# <<Металлург>> Магнитогорск

## Условие

Дано клеточное поле с $H$ строками и $W$ столбцами. Некоторые клетки (возможно, никакие) содержат магниты; все остальные клетки пустые.

Расположение магнитов описывается с помощью $H$ строк $S_1, S_2, ..., S_H$ длины $W$. Если в $i$-й строке $j$-й символ равен «#», в этой клетке магнит; если «.», клетка пустая.

Такахаши может перемещаться по полю следующим образом:
\beginitemize
\item Если какая-либо из соседних по стороне клеток содержит магнит, он не может никуда переместиться.
\item Иначе он может переместиться в любую соседнюю по стороне клетку. Однако он не может покидать поле.
\enditemize

Для клетки без магнита определим ее величину свободы как количество клеток, которые достижимы из нее по вышеописанным правилам перемещения. При этом клетка всегда считается достижимой из самой себя. Также необязательно, чтобы существовал путь, проходящий по всем достижимым клеткам. Для лучшего понимания ознакомьтесь с примерами.

Найдите максимальную величину свободы среди всех клеток поля.

## Формат входных данных

Первая строка содержит два целых числа $H$ и $W$ ($1 ≤ H, W ≤ 1000$).

Следующие $H$ строк содержат описание поля. $i$-я строка содержит строку $S_i$ длины $W$, описывающую $i$-ю сверху строку поля, состоящую из символов «.» и «#».

Гарантируется, что есть как минимум одна пустая клетка.

## Формат выходных данных

Выведите одно целое число~--- максимальную величину свободы среди всех клеток поля.
